# Piru

Piru 将剂量、带时间戳的笔记和药物浓度估算曲线放在同一条时间线上。离线物质资料库逐项标明数据来源，并允许你调整来源的优先顺序。

## 特色

- 在同一条时间线上对照剂量、会话笔记和药物浓度估算曲线。
- 从 PsychonautWiki Journal、DrugsPRO 及使用相同导出格式的其他应用导入日志。
- 与 [dose.wiki](https://dose.wiki/about) 正式合作，在应用内提供其物质数据。
- 查看物质数据的来源，并调整来源的优先顺序。
- 日志保存在你的设备上，可导出记录和加密备份。

<summary>完整功能</summary>
