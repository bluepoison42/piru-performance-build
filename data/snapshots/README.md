# `data/snapshots/` — resolved substance data

JSON, CSV, and category listings expose Piru's built substance database for inspection and review. `pipeline/build/snapshots.py` reads `Piru/Data/piru-substances.sqlite`, including resolved categories, curated overrides, and source priorities.

## Files

| File | Contents |
|---|---|
| `substances.csv` | One row per substance for spreadsheets and diffs; multi-value cells use ` \| `. |
| `substances.json` | Structured substance records. |
| `gaps.csv` | Substances with missing data. |
| `by-category/` | Category listings with canonical names, winning sources, and aliases, generated by `pipeline/audit/dump_substance_library.py`. |

## Notes

- Rebuild database and snapshots: `pipeline/build.sh fast`; snapshots only: `python3 pipeline/build/snapshots.py`.
- Commit snapshots with their changed inputs and manifest. [Source resolution and publishing](../../pipeline/README.md).
