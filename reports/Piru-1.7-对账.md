# 官方 1.7 与我们的 70015 对账

基准：已发布 Android `v1.7` / `8c8746ca`；我们的 `perf-1.6` / `8f498aae`，共同基线 `v1.6`。本表在合并源码前完成；新测试版用 `1.7.1 / 70016`。

官方新增：统一自定义日界、补记服药时间和记录时区、与仍在起效的既往剂量检查交互、按地区解析数字，以及资料来源和剂量数据修正。[官方说明](https://github.com/kageroumado/piru/releases/tag/android-v1.7)

| 我们的改动 | 决定 | 理由／合并方法 |
|---|---|---|
| 日界与夏令时计算 | 官方已覆盖 → 用官方 | `journalDay`、`journalDayStart`、`date(ofSlot:)` 已统一日历运算，删掉重复的 medicationDay 算法。 |
| Journal、日历、Insights 日分组 | 官方已覆盖 → 用官方 | 官方还认识每条记录的原时区；保留我们的跳过筛选。 |
| 凌晨日程排序及补记时刻 | 官方已覆盖 → 用官方 | 官方日程时钟覆盖凌晨排序，并新增按计划时间／当前时间记录。 |
| 改日界刷新 | 冲突 → 合并 | 使用官方分组刷新，保留我们对日程重算、提醒及缓存的刷新。 |
| 跳过／撤销及当日隔离 | 冲突 → 合并 | 官方仍无完整跳过入口，保留服务和 UI，日期判断改用官方日界。 |
| 历史 occurrence 修复 | 冲突 → 合并 | 保留已跳过状态及服药关联，匹配接入官方记录时区、指定槽位和我们的组合身份。 |
| 跳过不计依从性 | 冲突 → 合并 | 官方加入原时区和日界，但仍需我们的跳过快照与分母扣除。 |
| 快捷记录与底栏共用待服结果 | 冲突 → 合并 | 保留 occurrence 服务作为共同依据，合入官方时区窗口及指定服药槽位优先匹配。 |
| 撤销精确删除记录 | 官方已覆盖 → 用官方 | 官方已按槽位关联 UUID 定位记录，删除我们的重复实现与对应重复测试。 |
| 提醒时间缓存签名 | 不相关 → 直接搬 | 官方改日分组而未补完整提醒时间签名，保留现有缓存失效条件。 |
| 液体剂量精度及无效输入阻断 | 冲突 → 合并 | 保留原计算精度及浓度有效性；所有文本解析使用官方 `DecimalInput`。 |
| 组合液体缩放及数量计算 | 不相关 → 直接搬 | 官方未替代按产品定义缩放全部成分的修复。 |
| 组合品牌、剂型、异构体及盐型 | 不相关 → 直接搬 | 官方新时区字段不替代成分身份字段，保留编辑、导出及暂存全过程。 |
| 库存导入单位换算 | 冲突 → 合并 | 保留我们的合并换算，同时保留官方为系统生成库存记录写入未知时区。 |
| 原生导入 UUID 优先去重 | 冲突 → 合并 | 保留 UUID 规则，新增时区、计划槽位随原生 JSON 完整往返。 |
| PsyLog 未知剂量及导入后修历史 | 冲突 → 合并 | 保留我们的导入规则；外部文件不带时区时按官方传 nil，不伪造当前时区。 |
| 备份完整性及坏行阻断 | 不相关 → 直接搬 | 官方未改相应 PortableData 读取和备份保护，新增可空字段不算坏行。 |
| 删除全部前停用自动备份 | 不相关 → 直接搬 | 官方没有替代 Android 文件夹备份的停用顺序。 |
| 保存失败／临时库不覆盖备份 | 不相关 → 直接搬 | 官方恢复改进不替代备份来源与保存成功检查。 |
| 旧迁移来源保存成功后再删 | 不相关 → 直接搬 | 官方未改自定义物质的旧来源迁移。 |
| 数据库在线快照 | 冲突 → 合并 | 官方新增“所有用户模型计入非空判定”及只读探测；同时保留我们的 SQLite 在线备份和正常锁等待。 |
| PortableData 回滚、默认解码和缓存 | 不相关 → 直接搬 | 官方没有修改兼容层，新增记录字段按可空解码，磁盘表结构沿用。 |
| 无标点搜索 | 不相关 → 直接搬 | 官方只修求助关键词的弯引号，未覆盖药名、历史及快捷记录搜索。 |
| 托盘删除、展开与整组跳过 | 冲突 → 合并 | 保留我们的操作入口，同时保留官方交互提醒和编辑器避让 Record 按钮。 |
| 时间线扫描优化与颜色缓存 | 冲突 → 合并 | 官方改了日分片，邻接索引和颜色签名仍需要，分片时间改用官方日界。 |
| 绘制、阴影、Tab、冷启动优化 | 不相关 → 直接搬 | 官方未变更这些现有性能修复。 |
| Android 通知与 SAF 生命周期 | 不相关 → 直接搬 | 官方没有替代系统通知查询、清除及进程重建后恢复导出的修复。 |
| 旧通知测试计时修复 | 官方已覆盖 → 用官方 | 官方也改成比较实际触发时间，保留一份官方测试。 |
| 测试版身份与签名 | 冲突 → 合并 | 合入官方工程新增文件，包名、名称、profileable、原签名继续沿用，编号递增到 70016。 |
| 构建依赖与物质库 | 冲突 → 合并 | 沿用固定工具链与全依赖锁；物质库改为匹配 1.7 清单的固定资源。 |
| 验证范围 | 冲突 → 合并 | 跑相关官方日界／服药／数值／导出测试及现有升级回归，完成正式 APK 构建，不重复跑无关资料流水线或全量应用测试。 |

数据重点：1.7 的 `DoseEntry.timeZoneIdentifier` 与 `medSlotMinutes` 都是新增可空字段；70015 旧行应解码为 nil，保存重开仍保留剂量、日程、跳过状态及关联。使用旧格式 SQLite 经真实 ModelContainer 验证；本轮手机未连接。
